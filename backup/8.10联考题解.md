# Solution $10^{th} Aug. 2026AD$

## [AT_abc267_g](https://www.luogu.com.cn/problem/AT_abc267_g)

>正の整数列 $A=(a_1,a_2,\ldots,a_n)$ が与えられたとき、次の条件を満たす順列 $P=(p_1,p_2,\ldots,p_n)$ の数を求めよ。
 >
 > - $a_{p_i} \lt a_{p_{i+1}}$ となる整数 $i(1\leqslant i\leqslant n-1)$ がちょうど $k$ 存在する。
 >
>$998244353$ を法として求めてください。

考虑进行 DP。首先注意到对 $a$ 进行排序对结果没有影响。所以首先对 $a$ 增序排序。  
记 $s_i$ 表示与 $a_{i}$ 相同的数的个数，在排序后只需要统计相等平台即可得到。  
设 $f_{i,j}$ 表示将 $a_{1\dots i}$ 插入后存在恰好 $j$ 个 $a_{p_{x}} \lt a_{p_{x+1}}$ 的排列的数量。  
采取收集做法，则有两种$a_i$的插入情况可以扩散到 $f_{i,j}$ ：  

一种是未产生新的上坡，即由 $f_{i-1,j}$ 转移而来：  

- 由于增序排序，所以 $a_{i}$ 为当前最大，故插在开头必不产生新的上坡；  
- 可以插在任何一对上坡的中间，此时这一对上坡即被拆散，由左侧数与$a_i$产生新的上坡，从而整体上未增加上坡；  
- 可以插在数值相同的数后面，此时不增加上坡。  
共有 $s_{i}+j+1$ 种。  

一种是产生了新的上坡，即由 $f_{i-1,j-1}$ 转移而来，则不能产生的情况共有 $s_{i}+(j-1)+1=s_{i}+j$ 种，产生的情况即 $i-s_{i}-j$ 种。  
所以得到转移方程：  
$$f_{i,j}\gets (i-s_{i}-j)f_{i-1,j-1}+(s_{i}+j+1)f_{i=1,j}$$
代码：  

```cpp
#include <algorithm>
#include <cstdio>

using ll = long long;

const int P = 998244353;
const int N = 5005;

ll f[N][N];
int n, k, a[N], s[N];

int main()
{
    scanf("%d%d", &n, &k);
    for (int i = 1; i <= n; ++i)
        scanf("%d", a + i);
    std::sort(a + 1, a + n + 1);

    for (int i = 1; i <= n; ++i)
        (a[i] == a[i - 1]) && (s[i] = s[i - 1] + 1);

    f[0][0] = 1;
    for (int i = 1; i <= n; ++i)
        for (int j = 0; j <= i - s[i]; ++j)
            f[i][j] = ((j ? (f[i - 1][j - 1] * (i - j - s[i])) : 0) % P + f[i - 1][j] * (j + s[i] + 1) % P) % P;

    printf("%lld\n", f[n][k]);
    return 0;
}
```

## [AT_joisc2022_c](https://www.luogu.com.cn/problem/AT_joisc2022_c)

> 与えられた条件を満たす長さ $N$ の文字列 $S$ の個数を、 $10^9 + 7$ を法として求めてください。  
> ここで、 $T_i$ は $S$ の $i$ 番目の文字を取り除き、残りの部分を連結して得られる文字列とします。  
> 制約は $M$ 個の組 $(A_j, B_j)$ として与えられ、それぞれ $T_{A_j} \leqslant T_{B_j}$ であることが求められます。  

### 观察条件

对于题目所给限制条件，我们进行最简单的举例： $S = acccbba,(A,B)=(2,6)$  
那么根据定义： $T_{2}=ac|(c)cbb|a,T_{6}=ac|ccb(b)|a$  
不难发现， $T_{2}$ 和 $T_{6}$ 的前缀和后缀都是一样的，只有 $S_{2-6}$ 这一段有区别。  
那么观察并推广到任意 $i \lt j$ 的 $T_{i}$ 和 $T_{j}$  
发现 $T_{i,k} \neq T_{j,k}$ 等价于 $S_{k} \neq S_{k+1}$  
所以只需要找到 $[i,j]$ 部分中第一个相邻字符不相等的位置，就可以判断 $T_{i}$ 和 $T_{j}$ 的字典序  

### 设计DP

我们可以从右向左填充字符串。那么我们需要关注的就是当前字符往右第一个出现 $S_{x} \neq S_{x+1}$ 的位置 $x$ 以及其变化趋势（变大 or 变小）  
于是有状态 $f_{i,x,c,p}$ 表示当前填充 $S_{i}=c$, 向右第一个相邻字符不相等位置为 $x$ ， $p=0$ 表示 $S_{x} \lt S_{x+1}$ ， $p=1$ 表示 $S_{x} \gt S_{x+1}$ 。  
考虑转移。有两种情况：产生新的 $x$, 或保留原有 $x$  
如果保留原有 $x$, 即填入相同字符 $c$, 则有方程  
$$f_{i-1,x,c,p} \gets f_{i,x,c,p}$$
如果产生新的 $x$, 则填入不同字符 $d$, 则 $x\gets i-1, q\gets [c > d]$  
$$f_{i-1,i-1,d,q} \mathrel{+}= f_{i,x,c,p}$$
求和：  
$$f_{i-1,i-1,d,q} \mathrel{+}= \sum^{n}_{x=i}([q=2]\sum^{d-1}_{c='a'}f_{i,x,c,0/1}+[q=1]\sum^{'z'}_{c=d+1}f_{i,x,c,0/1})$$
此时再考虑合法性。  
如果 $A \gt B$, 那么当 $i=A$ 时，落在 $[A, B-1]$ 内的 $x$ 如果同时 $q=0$ 就需要清零；  
如果 $A \lt B$, 那么当 $i=B$ 使，落在 $[B, A-1]$ 内的 $x$ 如果同时 $q=1$ 就需要清零；  
于是我们得到了一个状态数 $O(26n^2)$ 的做法。  

### 进行优化

首先考虑空间上，我们求的答案并不关心更糟的状态，所以直接在原数组上修改，压掉一维，状态变为$f_{x,c,p}$  
再考虑时间上，首先求和符号之间互不关联，可以互换。然后对状态的下标进行调整  
$$
f_{d,q,i-1} \mathrel{+}=
\begin{cases}
\displaystyle \sum_{c=d+1}^{'z'} \sum_{x=i}^{n} f_{c,0/1,x}, & \text{if } q = 0 \\[4ex]
\displaystyle \sum_{c='a'}^{d-1} \sum_{x=i}^{n} f_{c,0/1,x}, & \text{if } q = 1
\end{cases}
$$
由于 $x \in [1,i)$ 的状态都是零，我们可以改一改：  
$$
f_{d,q,i-1} \mathrel{+}=
\begin{cases}
\displaystyle \sum_{c=d+1}^{'z'} \sum_{x=1}^{n} f_{c,0/1,x}, & \text{if } q = 0 \\[4ex]
\displaystyle \sum_{c='a'}^{d-1} \sum_{x=1}^{n} f_{c,0/1,x}, & \text{if } q = 1
\end{cases}
$$
那么我们惊讶地发现第一种状态转移除了被滚掉的 $i$ 之外什么都没有变化，可以直接拿来做初始值。  
显然需要数据结构优化。将复杂度为常数的 $(c,p)$ 拿出来做 $52$ 个数据结构是个不错的想法。每个数据结构下表是 $x$  
于是现在我们只需要考虑两种操作：  

1. 清空操作，将 $x \lt k$ 的状态全部清空  
2. 求和操作，求所有状态之和  

那么我们 ~~不难~~ 想到用栈优化：  
所有状态只会在字符变化时创建或弹出，滚动时无需操作（初值就是上一次的结果），字符变化时$c$不同，无需弹出，求和单独维护即可。时间复杂度是 $O(26n)$  
求答案时把栈里的元素全部倒出来求和，再加上被忽略的26种没有字符变化（aaaaaaaaaaa...）的答案即可  
于是就做完了  

### 代码

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>
#include <stack>

namespace Fujiwara
{
using std::vector;
using ll = long long;

const int P = 1e9 + 7;

int Azusa()
{
    int n, m;
    scanf("%d%d", &n, &m);

    vector<int> lim0(n + 1, 0);
    vector<int> lim1(n + 1, 0);
    for (int i = 1, a, b; i <= m; ++i)
    {
        scanf("%d%d", &a, &b);
        if (a < b)
            lim0[a] = std::max(lim0[a], b);
        else
            lim1[b] = std::max(lim1[b], a);
    }

    ll s[26][2]{0};
    std::stack<std::pair<int, ll>> st[26][2];

    for (int i = n - 1; i; --i)
    {
        vector<int> pre(26, 0), suf(26, 0);
        for (int j = 1; j < 26; ++j)
            pre[j] = (pre[j - 1] + s[j - 1][0] + s[j - 1][1] + 1) % P;
        for (int j = 24; j >= 0; --j)
            suf[j] = (suf[j + 1] + s[j + 1][0] + s[j + 1][1] + 1) % P;
        for (int j = 0; j < 26; ++j)
        {
            if (suf[j] > 0)
            {
                st[j][0].push({i, suf[j]});
                (s[j][0] += suf[j]) %= P;
            }
            if (pre[j] > 0)
            {
                st[j][1].push({i, pre[j]});
                (s[j][1] += pre[j]) %= P;
            }
        }
        for (int j = 0; j < 26; ++j)
        {
            while (!st[j][0].empty() && st[j][0].top().first < lim0[i])
            {
                (s[j][0] += P - st[j][0].top().second) %= P;
                st[j][0].pop();
            }
            while (!st[j][1].empty() && st[j][1].top().first < lim1[i])
            {
                (s[j][1] += P - st[j][1].top().second) %= P;
                st[j][1].pop();
            }
        }
    }

    ll res = 0;
    for (int i = 0; i < 26; ++i)
        (res += 1 + s[i][0] + s[i][1]) %= P;
    printf("%lld\n", res);
    return 0;
}
}  // namespace Fujiwara
int main()
{
    return Fujiwara::Azusa();
}
```
